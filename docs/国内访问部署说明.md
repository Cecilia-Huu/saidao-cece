# 国内访问部署说明（Vercel 常打不开）

Vercel（`*.vercel.app`）在国内无 VPN 时经常打不开。可选下面镜像。

---

## 方案 0：GitHub Pages（你们能开 GitHub 就优先用这个）

项目已配好 Actions。线上地址形如：

`https://Cecilia-Huu.github.io/saidao-cece/`

### 一次性操作

1. 在 GitHub 新建**公开**仓库，名字建议：`saidao-cece`
2. 本地推送：

```bash
cd internet-career-explorer
git add .
git commit -m "feat: 赛道测测初始版本，支持 GitHub Pages"
git branch -M main
git remote add origin https://github.com/Cecilia-Huu/saidao-cece.git
git push -u origin main
```

3. 打开仓库 → **Settings → Pages**
   - Source 选 **GitHub Actions**
4. 等 Actions 跑完（约 1～2 分钟），打开上面的链接即可发给同学。

> 若仓库名不是 `saidao-cece`，需要同步改：
> - `package.json` 里 `build:gh-pages` 的路径
> - `.github/workflows/deploy-github-pages.yml` 里的 `VITE_BASE_PATH`

---

## 方案 A：Netlify Drop（最快，约 1 分钟）

1. 解压桌面的 `saidao-cece-dist.zip`，或直接用文件夹 `saidao-cece-site`
2. 打开：https://app.netlify.com/drop
3. 把文件夹拖进去，得到 `https://xxxx.netlify.app`

---

## 方案 B：腾讯云 EdgeOne Pages（国内往往最稳）

1. 打开：https://pages.edgeone.ai/
2. 登录后上传 `saidao-cece-site` / `dist`

---

## 换电脑后重新打包

```bash
cd internet-career-explorer
npm install
npm run build          # Vercel / Netlify 根路径
npm run build:gh-pages # GitHub Pages 子路径
```
