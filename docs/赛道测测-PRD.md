# 赛道测测 · 产品需求文档（PRD）

| 字段 | 内容 |
|------|------|
| 产品名称 | 赛道测测（Saidao Cece） |
| 英文/代码名 | internet-career-explorer |
| 一句话定位 | 面向年轻人的互联网职业探索 H5：自我认知 + 轻量测评 + 岗位推荐 |
| Slogan | 测测你适合哪条互联网赛道 |
| 线上地址 | https://saidao-cece.vercel.app |

---

## 1. 背景与问题

应届生 / 转行者找互联网工作时，常见痛点：

1. **不知道自己适合什么**：岗位名词多（产品、运营、后端、数据…），缺少结构化自我认知工具。
2. **测评与推荐脱节**：市面性格测试好玩，但很少落到「具体互联网岗位 + 行动建议」。
3. **专业误导推荐**：仅按专业索引会推错岗（例如国际关系被推后端）；仅按性格又会推不现实工程岗。
4. **缺少下一步**：测完不知道去哪投、怎么准备面试、自己的卡点是什么。

**赛道测测**用趣味流程降低门槛，在兴趣、性格、情景、工具技能、学历专业之间做平衡匹配，输出可行动的结果页。

---

## 2. 目标用户

| 用户 | 诉求 |
|------|------|
| 大学生 / 应届生 | 探索互联网方向，准备校招 |
| 转行/跨专业同学 | 确认「兴趣 vs 专业门槛」是否可走 |
| 对互联网好奇的年轻人 | 7 分钟内获得人设 + Top 岗位 + 卡点对策 |

**非目标**：全行业职业规划、深度心理咨询、替代正式人才测评报告。

---

## 3. 产品目标

### 3.1 核心目标

- 完成一次完整测评后，用户能说清：**我是谁（人设）/ 我像什么性格 / 我适合哪几类岗 / 下一步做什么**。
- Top 推荐与「性格/兴趣/工具」体感一致，专业只做门槛，不「绑死」结果。

### 3.2 体验目标

- 全程约 **6～8 分钟**，移动端友好。
- 语气轻松、有彩蛋，但结果内容足够「能写进简历/面试」的颗粒度。

### 3.3 成功指标（建议后续埋点）

| 指标 | 说明 |
|------|------|
| 完成率 | 开始 → 结果页 |
| 人均停留 | 结果页停留时长 |
| 海报生成率 | 点击保存海报 / 完成测评 |
| 文案复制率 | 复制分享文案次数 |
| 岗位详情打开率 | Top6 卡片点击 |

---

## 4. 产品原则

1. **趣味入口，严肃输出**：兴趣岛好玩；优点/卡点/岗位要可落地。
2. **多信号融合**：兴趣岛（Holland）+ MBTI + 职场情景 + 已会工具 + 学历专业。
3. **专业是门槛不是唯一索引**：硬核工程岗对非对口专业强降权；有工具/技术信号时可放宽。
4. **性格主导排序**：工具加分封顶，避免多选盖过性格主序。
5. **隐私轻量**：答案存本地 `localStorage`，无登录、无服务端用户画像。

---

## 5. 用户流程

```
首页
  → 兴趣岛（选 3 座，并排序）
  → 答题（性格 / 职场情景 / 背景含工具多选）
  → 身份卡（学历 + 专业）
  → 结果页
       · 职业人设
       · MBTI + 兴趣岛
       · 优点（折叠）
       · 卡点+解法（折叠，可多开）
       · 推荐岗位 Top 6（可点开详情）
       · 身份建议 / 经验建议 / 面试彩蛋
       · 保存海报 / 复制分享文案
```

### 5.1 各步说明

| 步骤 | 交互要点 |
|------|----------|
| 首页 | 介绍模块；支持「继续上次进度 / 重新开一把」 |
| 兴趣岛 | 6 岛对应 Holland RIASEC；选满 3 个并排序（1/2/3 权重） |
| 答题 | 单选自动下一题；工具题为多选，确认后下一题；分节进度条 + 节末 cheer |
| 身份卡 | 学历、专业必选后进入结果 |
| 结果页 | 本地计算匹配；海报仅在生成时挂载，避免叠字 |

## 6. 功能需求

### 6.1 兴趣岛（Holland）

- 六岛：现实 R / 研究 I / 艺术 A / 社会 S / 企业 E / 常规 C。
- 用户选择并排序前三；写入兴趣分（权重约 8 / 5 / 3）。
- 答题中的「兴趣类问卷」下线，避免与选岛重复。

### 6.2 测评题库

| 板块 | 内容 | 用途 |
|------|------|------|
| 性格 | MBTI 四维度倾向题 | 人设 + 岗位风格匹配 |
| 职场情景 | 协作、优先级、压力等 | 价值观/行为偏好 |
| 背景 | 实习经历、能力方向、**已会工具（多选）**、目标赛道、节奏偏好 | 推荐校准 + 文案建议 |

**工具多选项示例**：Python / Java·Go·C++ / 前端 JS / SQL·Excel / Figma / 剪辑·AE / PPT·Notion / 都还在学。  
「都还在学」与其他选项互斥。

### 6.3 身份信息

- 学历：大专、本科、硕士、博士、已毕业等。
- 专业：计算机、电子信息、数理、经管、设计、传媒、人文/国关、其他。
- 用于：软门槛、身份建议文案、极少量 tie-break。

### 6.4 结果页

#### 职业人设（Persona）

六类人设（示例）：逻辑实干家、创意社交达人、稳健执行官、成长猎手、洞察探索者、体验造梦师。  
由性格/兴趣/背景 flag 打分选最高者。

每人设含：

- 优点：标题 + 标签 + 详述；默认收起，可多开。
- 卡点：标题 + 预警信号 + 详述 + 解法；默认收起，可多开（互不强制收起）。

#### 推荐岗位 Top 6

- 岗位库约 25 个方向（研发 / 产品运营 / 商业市场 / 职能）。
- 匹配分 = 性格·兴趣余弦相似 + 背景/目标加分 + **工具加分（有上限）** + 人设亲和 + 专业门槛调整。
- 卡片展示匹配度 %、赛道、简介；点击弹层：日常、技能、薪资区间、求职渠道、搜索词、面试 tip。

#### 分享

- 复制分享文案（人设 + MBTI + Top1 + 链接）。
- 生成结果海报（html2canvas）：预览弹窗 → 下载 PNG；生成时全屏遮罩，海报 DOM 用完即卸。

### 6.5 本地进度

- `localStorage` key：`saidao-quiz-v5`
- 存：当前页、答案、题目进度、兴趣岛、学历专业。
- 换电脑需重新测（本地存储不随包迁移，除非用户自行导出）。

## 7. 匹配算法（产品视角）

### 7.1 主排序

用户向量（MBTI 字母分、Holland 分、impact/growth/stability/creativity）与岗位 `ideal` 向量做余弦相似。

### 7.2 加分与门槛

| 信号 | 作用 |
|------|------|
| 背景 skill / goal / 压力偏好 | 小幅抬相关赛道 |
| 已会工具 | 抬对应岗位，**总分加封顶**，防多选碾压性格 |
| 人设亲和 | 让 Top6 与结果页人设同向 |
| 专业对口 | 仅约 2～3 分轻量加分 |
| 硬核工程岗 + 非对口 + 无技术信号 | 强降权（避免「国关→后端」） |
| 硬核工程岗 + 非对口 + 有代码/工具/技术目标 | 轻降权（允许真实意向冲进来） |
| 数据分析等偏洞察岗 | 人文等专业可进入（非一律当硬核研发挡） |

### 7.3 解释文案（Why）

结果详情中优先写：性格侧 / 兴趣侧 / 人设侧；专业与工具为补充说明。

## 10. 设计规范（摘要）

- 主色：海绿 `#0b3d3a`；强调色珊瑚 `#ff6b4a`；点缀金 `#f4c95f`；背景沙色系。
- 字体：展示用 Syne，正文 DM Sans。
- 卡片圆角大、分区清晰；结果页优点/卡点用折叠减少信息过载。
- 避免半透明卡片叠在固定海报上（已踩坑：叠字）。

---

## 11. 已验证的产品迭代（简史）

1. 岗位库扩充；去掉过度「大厂校招对齐」营销表述。  
2. 专业门槛：修复「国关→后端」；再平衡：防专业绑死 Top 推荐。  
3. 优点/卡点内容加深；卡点可多开；删通用「预警雷达」降冗余。  
4. Top3 → Top6。  
5. 增加「已会工具」多选，提升推荐精度。  
6. 海报：静默下载失败 → 预览下载；常驻底层海报 → 按需挂载，修叠字。

## 15. 一句话总结（面试可用）

> 「赛道测测」是一个纯前端的互联网职业探索 H5：用兴趣岛 + MBTI + 情景 + 工具技能 + 学历专业多信号匹配，在 7 分钟内给出职业人设、Top6 岗位与卡点对策，并支持海报分享；核心产品决策是「性格与工具主导推荐，专业只做门槛」。
