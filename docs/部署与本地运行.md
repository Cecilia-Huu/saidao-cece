# 部署与本地运行

## 环境要求

- Node.js 18+（推荐 22）
- npm 9+
- 可选：Vercel CLI（`npm i -g vercel`）

## 本地开发

```bash
cd internet-career-explorer
npm install
npm run dev
```

浏览器打开终端提示的本地地址（通常是 http://localhost:5173）。

## 构建

```bash
npm run build
npm run preview   # 预览 dist
```

产物在 `dist/`。

## 部署方式 A：Vercel（推荐）

1. 注册/登录 [vercel.com](https://vercel.com)（用你自己的账号）
2. 在项目目录：

```bash
npx vercel login
npx vercel          # 预览
npx vercel --prod   # 生产
```

3. 项目已含 `vercel.json`，用于 SPA 回退到 `index.html`。

自定义域名可在 Vercel Dashboard 绑定。

## 部署方式 B：Netlify Drop（最快、免 CLI）

1. 解压交接包里的 `saidao-cece-dist.zip`，或本地 `npm run build` 后用 `dist` 文件夹  
2. 打开 [https://app.netlify.com/drop](https://app.netlify.com/drop)  
3. 把文件夹拖进去即可获得公网 URL  

适合国内临时分享；注意 Netlify 免费域名与配额限制。

## 部署方式 C：任意静态托管

把 `dist/` 上传到：GitHub Pages、Cloudflare Pages、OSS+CDN 等。  
若托管方不支持 SPA fallback，需自行配置「所有路由 → index.html」（与 `vercel.json` 同理）。

## 常见问题

| 问题 | 处理 |
|------|------|
| `vercel.app` 打不开 | 国内网络 intermittently 失败；换网络或用 Netlify Drop |
| 改完题库但结果像旧的 | 清站点数据 / 换无痕；storage key 为 `saidao-quiz-v5` |
| 海报空白 | 用 Chrome；生成时等「海报生成中」结束再下载 |
| TypeScript 报错 | 先 `npm install`，确认 Node 版本 |

## 源码结构速查

```
src/
  App.tsx              # 页面状态机
  components/          # 首页/岛/题/身份/结果
  data/catalog.ts      # 题库、人设、渠道
  data/careers.ts      # 岗位库
  lib/matching.ts      # 匹配与本地存储
```
