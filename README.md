# 赛道测测（internet-career-explorer）

测测你适合哪条互联网赛道 —— 趣味职业探索 H5。

**在线体验：** [cecilia-huu.github.io/saidao-cece](https://cecilia-huu.github.io/saidao-cece/)

Vercel 版本继续保留为备用部署：https://saidao-cece.vercel.app

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS v4 · html2canvas

## 快速开始

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动构建并更新 GitHub Pages。

## 功能概览

兴趣岛（Holland）→ 性格/情景/工具测评 → 学历专业 → 人设 + Top6 岗位 + 卡点对策 + 海报分享。

匹配原则：**性格 / 兴趣 / 工具主导，专业做门槛。**
